# PC Agent icon

`PcAgent.png` is the source bitmap. `PcAgent.ico` contains 16, 24, 32, 48, 64, 128,
and 256 pixel frames used by Setup and the tray agent. Royal blue distinguishes
the companion from the dark server icon; the existing monitor/network glyph and
lime/cyan accents are retained.

Created with the built-in ImageGen edit tool on 6 September 2026 using the previous
application icon as reference, then converted to ICO frames with .NET Drawing.

Final edit prompt:

> Make an exact background-only recolor of the attached application icon, preserving the original glyph exactly. Change the dark background to solid royal blue #2458B8. Keep the monitor, arrows and network circles identical to the input. IMPORTANT the two network circles are hollow colored rings: their INSIDES must be the SAME BLUE as the background, never white dots. Keep flat solid colors, no texture, gradient or shadows. No checkerboard or white areas outside the icon: output a normal square image with the entire canvas royal blue. The existing glyph must have exactly the same placement, proportions and colors as the input. Do not enlarge the glyph. This will be downscaled to a Windows icon.
