# NDI Configurator PC Agent 0.7.2

Failed onboarding now records bounded stage timelines and exception details for internal diagnosis. Remote failures survive restarts and network outages in a seven-day retry queue, and are removed only after a matching server acknowledgement. Local server onboarding returns optional structured failure details through the existing process contract.

Setup returns a failing exit code when onboarding fails. The Agent captures UAC/launch failures and abnormal Setup exits without adding a second result dialog. Diagnostic uploads do not delay normal outcome reconciliation. Existing local confirmation, UAC and NDI configuration ownership are unchanged.

Use with Job Configurator 0.8.10 (0.8.10-dev.1 for Development) for server receipt and seven-day retention. Reports remain internal; no log viewer or report links are added to the UI.

Both companion validation projects and the server regression, frontend, installer, cross-repository and isolated diagnostic HTTP suites passed. Tests used isolated state and configuration paths.
