# NDI Configurator PC Agent 0.7.3

Fixes a Windows Firewall COM marshalling error that stopped agent installation and onboarding with "Value does not fall within the expected range." The interface list now uses the array representation Windows requires. The validation suite reproduces the old failure and verifies both UDP and TCP policies against real, unregistered Windows COM rule objects without changing the live firewall.

Internal onboarding reports now preserve the underlying installation exception and its stack information. This release includes the seven-day diagnostic retry queue and server-local failure reporting introduced in 0.7.2. No diagnostic logs are added to the UI.

Use with Job Configurator 0.8.11, or Development 0.8.11-dev.1. This patch supersedes 0.7.2 after the fault was found during the user-authorized local deployment.
