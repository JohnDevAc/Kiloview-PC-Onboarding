# NDI Configurator PC Agent 0.7.1

This release improves remote onboarding recovery, validates persisted endpoint and network identity, and prevents unreachable servers or malformed journal records from blocking later confirmations. Installation preserves a complete recoverable Setup/Agent pair and the original desktop user's identity. Downloads require the necessary source to be reachable unless a verified local package is available.

PC NDI configuration remains owned by the companion. Client-only installations do not require a local Job Configurator server. Remote approval and UAC remain required; the installed server-local schema-1 contract uses existing elevation.

Validation: 18 Setup groups, 22 Agent groups, and 11 cross-repository onboarding scenarios passed before release preparation.
